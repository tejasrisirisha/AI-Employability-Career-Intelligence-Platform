# 🎓 AI Employability & Career Intelligence Platform

An end-to-end AI system for predicting student placement outcomes and guiding
students toward better employability — built for the problem statement:
**"AI Based Student Employability & Placement Prediction System."**

## Pipeline implemented (matches your Version 2 spec)

```
Student Profile
   ↓
AI Employability Assessment
   ↓
Placement Probability
   ↓
Explainable Prediction        (SHAP if installed, else transparent fallback)
   ↓
Skill Gap Analysis            (radar chart vs. best-fit role)
   ↓
Job Role Matching             (6 roles, ranked % match)
   ↓
Resume Analysis               (PDF/TXT upload, keyword-based skill extraction)
   ↓
Personalized Improvement Plan (prioritized, auto-generated)
   ↓
What-If Simulator             (live "drag sliders, see probability change")
   ↓
Progress Tracking             (saved snapshots + trend chart)
```

## 📁 Files

| File | Purpose |
|---|---|

## 🚀 Quick start

```bash
# 1. Create environment & install dependencies
pip install -r requirements.txt

# 2. (Already done for you — files are included) Regenerate if you want fresh data/models:
python generate_dataset.py
python train_model.py

# 3. Launch the app
streamlit run app.py
```

The app opens at `http://localhost:8501`.

## 🧠 About the dataset & model

Public placement datasets (e.g. Kaggle's "Campus Recruitment") only have
~215 rows and ~10 shallow columns — not enough for a multi-feature,
explainable system with 20 inputs, skill-gap analysis, and job-role matching.

So `generate_dataset.py` builds a **6,000-row synthetic dataset** whose
`Placed` label is generated from a transparent, weighted scoring formula
based on real placement-research factors (CGPA, internships, projects,
aptitude, technical/coding/communication skill, backlogs, certifications,
placement training, etc.) **plus realistic random noise** — so the signal is
genuinely learnable (not random) but also not artificially perfect.

Current trained-model performance (see `models/metrics.json`):

- **Best model:** Gradient Boosting Classifier (chosen automatically after
  comparing Random Forest, Gradient Boosting, and Logistic Regression)
- **Accuracy:** ~78%
- **ROC-AUC:** ~0.85
- **F1-score:** ~0.66
- A second **Random Forest Regressor** predicts expected package (LPA) for
  students likely to be placed (R² ≈ 0.58 on held-out placed students).

These numbers are realistic for a placement-prediction task (real-world
campus placement outcomes depend on many unmeasured factors — company
requirements, interview-day performance, luck, etc.) — a model claiming
99%+ accuracy on this kind of problem would be badly overfit.

To use your **own real dataset** instead: replace
`data/student_employability_dataset.csv` with your data (keep the same
column names, or edit `NUMERIC`/`CATEGORICAL` lists in `train_model.py`),
then re-run `python train_model.py`.

## ✨ Features in the app

- **Sidebar student-profile form** — 20 inputs (academics, experience, skills, aptitude)
- **Employability dashboard** — probability gauge, employability score, predicted
  package, peer percentile, and a histogram showing where you land vs. 6,000 peers
- **Explainable AI tab** — SHAP-based per-student explanation (falls back to a
  transparent feature-importance heuristic if `shap` isn't installed)
- **Skill Gap Analysis** — radar chart of you vs. your best-fit role, plus a
  ranked table of specific gaps to close
- **Job Role Matching** — % match across 6 common entry-level roles
- **Resume Analysis** — upload a PDF/TXT resume, get automatic keyword-based
  skill extraction and ATS-style coverage scoring
- **Personalized Improvement Plan** — priority-ranked action items + a
  30-day action sprint
- **What-If Simulator** — live sliders to test "what if I raised my CGPA /
  did 2 more internships" without touching your saved profile
- **Progress Tracking** — save dated snapshots and see your trend line over time

## ⚠️ Disclaimer

This is an educational project. Predictions are generated by a model trained
on synthetic (logic-grounded) data and are indicative only — not a guarantee
of real placement outcomes.
